# Shivansh International Asset Structure

This directory contains static assets served directly by the web server.

## Structure

- `/branding/`: Contains core brand assets.
  - `logo.png`: Main company logo used in Header and Footer.
- `/labeled_assets/`: Product images mapped to specific SKUs.
  - These are generated by the `labeling_agent.py` script.
  - The path used in `src/lib/data.ts` should be `/labeled_assets/[filename]`.

## Maintenance

- To update the logo, replace `/branding/logo.png`.
- To add new products, run the asset pipeline:
  1. `extract_pdfs.py`: Extract raw images from catalogs.
  2. `labeling_agent.py`: Map images to SKUs (outputs to `public/labeled_assets/`).
  3. `generate_data.py`: Update `src/lib/data.ts` with new product metadata.
